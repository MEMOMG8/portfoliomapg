# Projects laptop

Model: Macbook, by sriniwasjha, originally distributed through Pmndrs Market.
Retrieved from Alvaro Saburido's public course repository:
https://github.com/alvarosabu/midudev-tres-desk-configurator-course/blob/main/lessons/animation/public/models/laptop.glb

The repository's README explicitly identifies this model as CC0:
https://github.com/alvarosabu/midudev-tres-desk-configurator-course#licencia

Modifications: custom studio lighting, silver materials, printed keyboard legends,
Pipeline Sentinel screenshot mapped to the display, camera framing, and grouping
the camera ring with the lid. This is not Trackly's asset or footage.

Project screenshots and labeled concept illustrations are mapped to the display
using camera-projected screen coordinates.
Renderer: Blender 4.2.1 LTS, Cycles CPU, 12 samples with denoising.
Motion: motion.mp4, 800 x 640, 24 fps, 2.5 seconds.
Poster: poster.webp, opening frame.
It turns the laptop 37 degrees and partially closes/reopens its actual lid.

Used only in the featured Projects carousel.
